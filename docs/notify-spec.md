# 通知整合規格（商品訂單＋贊助）

2026-09-04 盤問定案（/grill-me 41 題）。開工前站長點頭；開工後照此實作，不另做解讀。

## 一、範圍
- 商品訂單與贊助的**所有**客人通知一起整合：成立／取號、待付款提醒、付款失敗、付款完成、出貨、定期定額扣款成功與失敗。
- 站長端：新的「提醒中心」、後台可改的通知文案、全站暫停開關。
- 不動：投稿通知、站長營運信、夥伴出貨信。

## 二、提醒節奏（商品與贊助相同）
- 從**下單那一刻**起算，不是一次接一次累加：
  - 第 1 次：下單後 10 分鐘
  - 第 2 次：下單後 12 小時
  - 第 3 次：下單後 24 小時（文案多一句「這是最後一次提醒」）
  - **第 48 小時判失敗**：訂單取消、庫存回補、寄失敗通知；贊助標失敗。
- ATM：虛擬帳號效期改 **2 天**（現在 3 天），帳號失效與訂單失效同一刻。ATM 的三次提醒時間同上，取號當下那一則繳費資訊不算提醒。
- 企業付款連結訂單：維持 3 天／7 天的節奏不變，但一樣進提醒中心、一樣可手動。
- 換付款方式後三次**重算**；最多重算一次（一張單最多兩輪六次）。
- 手動提醒也算一次、並從那一刻重新計時。
- 深夜：晚上 10 點到早上 8 點之間到期的 LINE 與簡訊延到早上 8 點送；信不受限。
- 自動對帳改成**每 5 分鐘**跑一次（現在 15 分鐘），10 分鐘那一則最多晚 5 分鐘。
- 失敗通知之後不再自動提醒，只留手動。

## 三、每一次提醒用哪些管道
- 有綁 LINE：信＋LINE，每次都發。
- 沒綁 LINE：信＋簡訊，每次都發（含失敗通知）。
- 每一則都給兩條路：「繼續付款」（同一張單、同一方式接續）與「重選付款方式」。信與 LINE 放兩顆；簡訊只放「接續付款」一條（付款頁本來就有換方式按鈕）。
- 「重選付款方式」連到感謝頁的新狀態：待付款也能看到三顆換方式按鈕，換了方式同一張單、庫存不動。贊助頁同理。
- 信箱被標記寄不到：只走 LINE／簡訊。LINE 額度用完：自動退回簡訊（現有機制）。

## 四、付款失敗通知
- 商品維持現有；**贊助新增**，沿用商品的文案結構與免重填連結。
- 文案分兩類：一次性（刷卡被擋、LINE Pay 沒請款、ATM 到期、從未進金流頁）用「換個方式再試」，ATM 到期加一句「原本的帳號已失效，按下去會重新產生」；定期定額首期授權失敗用「授權沒完成，重新設定一次」。
- 「同一人後來已付款成功」不提醒也不寄失敗通知：Email 或手機任一相同就算同一人；商品只看商品、贊助只看贊助。
- 既有失敗贊助：上線當天跑一次補寄，只對「7 天內失敗、之後沒再贊助成功」的人。

## 五、定期定額扣款失敗（新）
- 當天通知一則（信＋LINE）：「這一期沒扣到，綠界接下來幾天會再試；卡片換了就按這裡重新設定，舊的會自動停掉」，連到贊助頁月捐。
- 連續兩期失敗：標成暫停、通知一次「每月支持已暫停」，之後不再吵。
- 事實：綠界會自動重試；沒有「更新卡片」功能，只能重新申請一次月捐並取消舊的。

## 六、提醒中心（後台新分頁）
- 位置：訂單那組，「訂單／提醒／待聯絡」，提醒與待聯絡併成一頁兩個分頁籤，資料互通。
- 列出所有待付款與付款失敗的商品訂單＋贊助（含卡很久還沒判失敗的）。
- 每筆欄位：類型（商品／贊助）、編號、姓名、金額、付款方式、狀態、已提醒次數與最近一次時間、下一次自動提醒時間、管道狀態（信／LINE／簡訊三個小燈）、「同一人後來有付款成功」警示。
- 動作：一鍵提醒（照規則）、選管道與內容（跟訂單頁「通知客人」同一區）、停止自動提醒、標記已聯絡。
  - 「標記已聯絡」：只從清單消失，自動照走；可還原。
  - 「停止自動提醒」：不再寄也不進清單；可還原。
  - 手動提醒不受三次上限，第四次起按下去先確認。
- 訂單頁與訂單列表原本的提醒按鈕維持。
- 頁面顯示本月 LINE 用量；75% 警告信照舊。
- 待聯絡門檻：付款失敗的贊助全部進清單，沒電話的顯示寄信路徑（跟商品一樣）。
- 失敗不寄站長信。

## 七、文案（全部後台可改）
- 後台新頁「通知文案」：每一則通知一張卡，三格「主旨」「第一段」「按鈕文字」，LINE 與簡訊各一格（簡訊顯示剩餘字數）。變數用中文大括號 {姓名}{訂單編號}{金額}{期限}{付款方式}，旁邊一排按鈕點了就插入，下面即時預覽。留空用預設。不出現任何英文代碼。
- 贊助的 LINE 改成模板：贊助取號、付款完成、待付款提醒、付款失敗、扣款失敗，與訂單模板同一頁。
- 預設文案（親切體，第三次只多「這是最後一次提醒」）：

| 事件 | 主旨 | 第一段 |
|---|---|---|
| 訂單成立 | 收到訂單 {訂單編號}｜佑在幹嘛｜則佑 | 我們已收到你的訂單，完成付款後會盡快為你出貨。 |
| 取號 | 你的轉帳帳號 {訂單編號}（贊助：轉帳帳號：{帳號}） | 你好，這是你的轉帳帳號，期限前完成就好。帳號、金額、期限各一行。 |
| 提醒第 1 次 | 還差一步：訂單 {訂單編號} 還沒完成付款 | 你好，你的訂單還沒完成付款，商品先幫你留著。按「繼續付款」接續，或「重選付款方式」換一種。 |
| 提醒第 2 次 | 再提醒一次：訂單 {訂單編號} 還沒完成付款 | 同第 1 次 |
| 提醒第 3 次 | 最後一次提醒：訂單 {訂單編號} 還沒完成付款 | 第 1 次＋「這是最後一次提醒，之後這筆訂單會自動取消，不會有任何費用。」 |
| 付款失敗 | 付款沒有完成（沒有扣款）{訂單編號} | 你好，這筆訂單的付款沒有完成，也沒有扣款。想再試的話，按下面任一種方式，資料不用重填。 |
| 付款完成 | 付款完成 {訂單編號} | 維持現況 |
| 已出貨 | 已出貨 {訂單編號} | 維持現況 |
| 贊助成功 | 收到你的支持了／每月支持已生效 | 維持現況 |
| 扣款成功 | 本月扣款完成 {金額} | 維持現況 |
| 扣款失敗 | 這一期沒有扣款成功 | 你好，這個月的支持沒有扣到，綠界接下來幾天會再試。如果卡片換了，按這裡重新設定，舊的會自動停掉。 |
| 連續兩期失敗 | 每月支持已暫停 | 連續兩期都沒扣到，我先把它停下來，不會再嘗試。想繼續的話按這裡重新設定一次。謝謝你一路的支持。 |

- LINE 提醒：「{姓名} 你好，訂單 {訂單編號}（NT${金額}）還沒完成付款。繼續付款：連結一。重選付款方式：連結二。」第 3 次開頭加「最後一次提醒。」
- 簡訊提醒：「{姓名} 你好，訂單 {訂單編號} 還沒完成付款，點連結接續或換方式。」第 3 次開頭加「最後一次提醒：」
- 失敗（LINE／簡訊）：「付款沒有完成，沒有扣款。想再試按這裡，資料不用重填。」（拿掉「發卡行擋下」；ATM 到期也用這則）
- 贊助版把「訂單 {訂單編號}」換成「你的支持 NT${金額}」。

## 八、上線方式
- 全站暫停開關（網站設定），開著時後台每頁提示。
- 第一天 dry run：只記錄不寄，提醒中心顯示「本來會寄給誰」，站長看過再打開。
- 既有舊單一律從上線時間開始計時，不追溯。
