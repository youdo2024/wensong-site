## 中華電信 DNS 設定

- [ ] A 紀錄：`wensong.tw` → Zeabur 提供的 IP
- [ ] A 紀錄：`www.wensong.tw` → Zeabur 提供的 IP
- [ ] CNAME 紀錄：`www.wensong.tw` → Zeabur 指定的主機（替代或補充 A 紀錄）
- [ ] MX 紀錄：保持 Google Workspace 設定，不變動
- [ ] TXT 紀錄 (SPF)：`v=spf1 include:_spf.google.com ~all`
- [ ] TXT 紀錄 (DKIM)：從 Google Workspace 管理台產生，貼到 DNS（應用程式 → Google Workspace → Gmail → 驗證電子郵件）
- [ ] TXT 紀錄 (DMARC)：`_dmarc.wensong.tw` 值 `v=DMARC1; p=none; rua=mailto:hi@wensong.tw`
