# 後台資訊架構（第 2 步產出，2026-09-05）

站長在兩輪 grill 裡拍板的規則全部收在這裡。畫布（第 3 步）與程式（第 4、5 步）都以這份為準；要改先改這份。

## 0. 不變的東西

- 品牌一條不動：米袋色、2px 茶墨框、直角、硬陰影、點點動畫。只改層次與操作。
- **字體例外（站長 2026-09-05）：後台全部改黑體（Noto Sans TC），標題也是，字距沿用。** 前台不動。
- 字級 14／12／16（內文／副文／標題），手機桌機一樣，不放大。
- 間距只有三層：8（元素內）、14（元素間、卡片間）、24（區塊間）。
- 四個語意色：琥珀＝待處理（待付款、待出貨、待審、待催）；朱紅＝失敗、逾期、刪除、主動作；綠＝完成、正常；灰＝其他。靛藍從後台拿掉。
- 設計基準寬 402（iPhone 17 Pro），360 到 430 都要過，桌機 1280。

## 1. 導覽

### 側欄五組（入口不減，共 24 個）

| 組 | 入口 |
|---|---|
| 每天看 | 總覽、訂單、提醒、贊助 |
| 賣東西 | 商品、銷售工具（付款連結、企業訂購）、夥伴出貨、折扣碼、結算報表 |
| 跟人聯絡 | 名單總覽、會員名單、待聯絡、發送、電子報、簡訊、LINE |
| 內容 | 文章、投稿、精選影片、地圖廚師 |
| 設定 | 商店、贊助、金流、通知、內容、系統 |

- 原本靠頁內分頁才到得了的 7 頁全部升格成側欄入口，分頁列可以保留當同組內的快速切換。
- 「文案信件」併進「設定·內容」，「通知文案」併進「設定·通知」，側欄不再有這兩個入口。
- 桌機：側欄常駐，組名是小標。手機：頂列「選單」開全螢幕抽屜，五組分類清楚列出；底欄固定五個：總覽、訂單、提醒、贊助、商品。

### 舊網址

- `/admin/settings` 變成目錄頁：六張卡，每張一句話說這頁管什麼。不是「更多」。
- `/admin/copy`、`/admin/notify-copy` 導向新位置。

## 2. 設定拆六頁（各自儲存）

現在的 19 個區塊怎麼分：

| 新頁 | 收進來的舊區塊 |
|---|---|
| 商店 | 商店、運費費率表、付款方式、文章頁的支持商品 CTA、首頁圖片 |
| 贊助 | 贊助方案、結帳加購贊助、贊助 |
| 金流 | 金流與發票環境、商店金流、金流與信件（兩個「金流與…」合併成一段說明） |
| 通知 | 自動提醒、信件副本、LINE 推播、通知文案（原獨立頁） |
| 內容 | 社群連結、隱私權、使用條款、退換貨政策、投稿條款、文案信件（原獨立頁） |
| 系統 | 備份、預覽金鑰、測試信、環境資訊（現在散在各區的工具鈕集中到這裡） |

- 每頁一顆儲存，手機黏在螢幕底部，有未儲存改動時亮起。
- 改了沒存要離開，跳出三選：儲存後離開、不存離開、留下。不自動丟、不自動存。此規則套到所有有儲存鈕的表單（六個設定頁、商品、文章、廚師、影片編輯）。

## 3. 總覽

- 上半：本月數字。營收、贊助金額、訂單數、贊助筆數，四格。
- 下半：今天要處理。待付款幾筆、該催幾筆、該出貨幾筆、待審投稿幾篇、待聯絡幾位，每格點了直接進篩好的列表。
- 移除：最新訂單、最新贊助、贊助來源統計、各區瀏覽次數。來源統計搬到贊助列表頁尾工具區，瀏覽次數搬到文章列表。

## 4. 列表頁（訂單、贊助、投稿、名單共用同一套）

- 頁首：標題＋一句話說明。
- 一條篩選列：狀態膠囊（全部、待付款、已付款、已出貨、失敗）＋搜尋框＋視圖切換（卡片／表格）。
- 列表：桌機表格。**手機改成一行一單（站長 2026-09-05 選甲）**：沒有卡片，一行兩層，左邊姓名加編號末四碼與時間，右邊金額加狀態色點；整行可點進詳情；列表上不放動作鈕，動作在詳情做，一鍵催款去提醒中心。一屏約 8 筆。狀態膠囊列保留在最上面，搜尋框在膠囊下面。
- 贊助、投稿、名單列表比照同一套。
- 頁尾工具區：匯出 CSV、對帳、清空之類的低頻工具，收合。
- 統計卡從列表頁移除（搬到總覽）。

## 5. 訂單詳情

由上到下：
1. 狀態列：狀態（語意色）、金額、付款方式、下一步該做什麼一句話。
2. 動作列：通知客人、出貨、改付款、改數量。點了才展開對應表單，同時只展開一個。
3. 收件資訊（多地址單在這裡展開名單）。
4. 明細。
5. 寄件紀錄（最近 10 封）。
6. 結帳連結（若有）。
7. 刪除，在最底，紅框，要確認。

**已決定（2026-09-05）：手機用 B 方向（狀態列＋「動作／資料／紀錄」三個分頁籤，一次只看一塊，刪除在動作清單最底）；桌機用 A 方向（左欄狀態列與動作、右欄資料與紀錄，一頁看完）。**

贊助詳情目前沒有獨立頁，第 5 步做到贊助時再決定要不要開。

## 6. 元件清單（第 4 步要做的）

PageHead（標題＋一顆主動作）、StatusBar（狀態列）、ActionRow（動作列，展開表單）、Card、KV（鍵值表）、SwitchRow（沿用）、FilterBar（狀態膠囊＋搜尋＋切換）、StickySave（黏底儲存列，含未儲存提示）、Empty（空狀態一句話）、DangerZone、Drawer（手機全螢幕選單）。既有 Switch、Check、ViewToggle、RemindButtons 保留並套 token。

## 7. 畫布範圍（第 3 步）

四張畫面，各手機 402 與桌機 1280：總覽、訂單列表、訂單詳情、設定·通知（拿它當設定頁樣板，因為開關最多）。訂單詳情兩個方向已挑定（手機 B、桌機 A）。

## 8. 上線順序（第 5 步）

訂單詳情 → 訂單列表 → 總覽 → 設定六頁 → 贊助 → 提醒 → 發送 → 其餘。每批做完給前後對照，等站長說推。
