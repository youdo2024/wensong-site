# 問爽的詞彙庫

給 WhisperX 辨識前用、辨識後校對用的一套詞彙工具。這個資料夾裡：

- `詞彙表.md`：分類詞彙庫，人工校對逐字稿時查。
- `prompt.txt`：給 WhisperX `--initial_prompt` 用的一行提示詞。
- `替換表.tsv`：錯字\t正字，給 `fix.mjs` 讀。
- `fix.mjs`：批次修正 `out/<key>.md`，輸出 `out/<key>.fixed.md`，不覆蓋原檔。

這套東西不會動 `tools/transcribe/run.sh`，也不會動正在跑的批次（tmux session `wensong-transcribe`）。要套用 prompt，要自己手動改 `run.sh`，見下面說明。

## WhisperX 支不支援提示詞

**支援。** 查證方式與結論：

```
~/.local/pipx/venvs/whisperx/bin/whisperx --help | grep -i prompt
```

跑出來有兩個相關參數：

```
--initial_prompt INITIAL_PROMPT
                    optional text to provide as a prompt for the first
                    window. (default: None)
--hotwords HOTWORDS   hotwords/hint phrases to the model (e.g. "WhisperX, ...")
```

再去看 site-packages 底下的原始碼確認怎麼接進辨識流程：

- `whisperx/__main__.py:60` 定義 CLI 參數 `--initial_prompt`。
- `whisperx/transcribe.py:108` 把 `args.pop("initial_prompt")` 塞進 `asr_options` dict。
- `whisperx/asr.py:47-50`：`options.initial_prompt` 非空時，會被編碼成 token，塞進辨識序列的開頭（`all_tokens.extend(initial_prompt_tokens)`）。

**正確參數是 `--initial_prompt`**（字串，直接接在 whisperx 指令後面）。要注意兩件事：

1. `--initial_prompt` 官方說明寫「for the first window」，也就是**只影響檔案最開頭那一小段辨識**，不是整篇逐字稿都持續生效。長音檔（問爽的很多集 40 分鐘以上）中後段不會因為這行提示詞而變準，主要效果是把片頭的節目名、人名先「校準」對。
2. `--hotwords` 是另一個獨立參數（熱詞/提示片語），效果和 `--initial_prompt` 不完全一樣，這次只用 `--initial_prompt`，`--hotwords` 沒有動用，之後如果要試「全程加權」可以再研究。

### 怎麼在 run.sh 加（不要真的改 run.sh，這裡只記怎麼加）

`run.sh` 裡呼叫 whisperx 的地方（目前的樣子）：

```bash
"$WHISPERX_BIN" "$MP3" \
    --model "$MODEL" \
    --language zh \
    --compute_type "$COMPUTE_TYPE" \
    --device cpu \
    --batch_size "$BATCH_SIZE" \
    --output_dir out \
    --output_format json \
    ${DIARIZE_ARGS[@]+"${DIARIZE_ARGS[@]}"} \
    > "out/$KEY.log" 2>&1
```

要加提示詞，多加一行 `--initial_prompt "$(cat glossary/prompt.txt)"` 即可，例如：

```bash
PROMPT="$(cat "$SCRIPT_DIR/glossary/prompt.txt")"

"$WHISPERX_BIN" "$MP3" \
    --model "$MODEL" \
    --language zh \
    --compute_type "$COMPUTE_TYPE" \
    --device cpu \
    --batch_size "$BATCH_SIZE" \
    --initial_prompt "$PROMPT" \
    --output_dir out \
    --output_format json \
    ${DIARIZE_ARGS[@]+"${DIARIZE_ARGS[@]}"} \
    > "out/$KEY.log" 2>&1
```

`prompt.txt` 只有一行、200 字以內，直接 `cat` 進變數即可，不用額外處理跳脫字元。

現在這批（tmux `wensong-transcribe`）已經在跑，等這批跑完、要重新處理沒跑好的集數，或之後重新整批重跑時，再考慮把這行加進 `run.sh`。

## fix.mjs 用法

```bash
cd tools/transcribe/glossary
node fix.mjs 0        # 修 out/0.md，輸出 out/0.fixed.md
node fix.mjs 13
node fix.mjs --all    # 修 out/ 底下所有 *.md（跳過已經是 .fixed.md 的檔案）
```

原檔不會被動到，输出永遠是 `out/<key>.fixed.md`，方便對照校對。`out/` 整包被 `.gitignore` 排除，`.fixed.md` 不會意外進版控。
